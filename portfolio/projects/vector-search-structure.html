기술 스택
Python LLM Vector Search
프로젝트 설명

LLM과 vector 유사도 검색을 활용해 자료 검색 구조를 설계한 프로젝트입니다.

배경 및 목표

사용자가 필요한 자료를 더 빠르게 찾을 수 있도록 의미 기반 검색 흐름을 구성하는 것을 목표로 했습니다.

데이터 수집 및 전처리

검색 대상 문서를 정리하고 임베딩 및 메타데이터 설계를 검토했습니다.

분석 방법론

문서 분할, 벡터화, 유사도 검색, LLM 응답 생성 흐름을 기준으로 구조를 설계했습니다.

분석 결과 및 인사이트

키워드 검색만으로 찾기 어려운 관련 자료를 의미 기반으로 탐색할 수 있는 가능성을 확인했습니다.

비즈니스 제안 및 액션 아이템

자료 검색 품질 개선을 위해 검색 결과 평가와 문서 관리 기준을 함께 제안했습니다.
