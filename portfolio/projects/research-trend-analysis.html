프로젝트 설명

기반 기술을 연구하는 부서로부터, 790편의 논문 데이터를 기반으로 연구 트렌드를 파악하고 다음 출원 주제 인사이트를 도출할 수 있는 논문 분석을 의뢰받았습니다. 연구 논문의 인사이트 도출은 도메인 지식이 충분해야 가능하므로, 해당 분석의 목표는 "연구원이 보다 쉽게 인사이트 도출에 다가갈 수 있는 분석 결과"로 설정했습니다. 주제별 키워드 빈도 집계와 더불어, 주제별로 함께 등장하는 키워드를 군집화하여 연구 흐름의 맥락과 키워드 간 관계를 파악할 수 있도록 분석을 설계했습니다. 분석 결과는 사내·사외 IFSCC 트렌드 발표에 활용되었으며, 직접 구축한 사내 논문 검색 사이트와 연동되어 클러스터 키워드를 검색어로 활용할 수 있도록 연결되었습니다.

분석 대상 및 결과
  • 분석 대상 : 2025 IFSCC 전체 논문
  • 총 790편 / 15개 세션 카테고리
  • 카테고리별 3~22개 클러스터 생성
배경 및 목표

IFSCC는 화장품 과학 분야 최대 국제 학술대회로, 매 회차 수백 편의 논문이 발표됩니다.
연구원이 전체 논문을 직접 읽고 트렌드를 파악하는 것은 물리적으로 한계가 있어, 키워드 기반 트렌드 분석이 의뢰되었습니다.

15개 카테고리별 연구 트렌드를 키워드 군집으로 시각화하고, 그 결과를 발표 자료와 논문 검색 사이트에 실제로 연결

데이터 수집 및 전처리
데이터 수집
  • 2025 IFSCC 전체 논문 790편 PDF (연구원으로부터 직접 제공)
  • 논문 메타데이터 엑셀 (논문번호, 논문명, 세션 주제, Podium 여부)
전처리
  • PyMuPDF로 PDF 텍스트 추출 후 논문번호 기준으로 메타데이터와 조인
  • PDF 추출 과정의 노이즈 제거 (줄바꿈 하이픈, 참고문헌, DOI/URL, 인용번호 등)
  • 영문 텍스트 정규화 (유니코드 정규화, 소문자 변환, 특수문자 제거)
  • spaCy 기반 형태소 분석 — 명사·형용사·동사 중심 토큰 추출 및 표제어(Lemmatization) 변환으로 단어 형태 통합
  • 도메인 특화 불용어 제거 — 일반 영문 불용어 외 cosmetic, study, result 등 논문 전반에 반복되나 트렌드 구분에 기여하지 않는 단어를 별도 사전으로 구축하여 제거
  • Bigram 포함 토큰화 — 결합되어 사용되는 키워드와 단일 키워드를 구분하여 추출
  • 세션별 논문 수 편차(약 20~100편 이상)를 고려하여 TF-IDF 파라미터 동적 조정
  • 카테고리별 TF-IDF 평균 분포 기준 상위 20% 중요 키워드만 선별하여 노이즈 감소
분석 방법론
TF-IDF 벡터화

각 카테고리 내에서 논문별로 키워드 중요도를 수치화

  • 카테고리별 전체 문서 대상 TF-IDF 계산
  • 단일 키워드 + Bigram 함께 활용
클러스터링 (HDBSCAN)

군집 수를 사전에 정하지 않고, 키워드 간 밀도 기반으로 자동 군집화

  • 키워드 간 유사도를 코사인 거리로 계산
  • 카테고리별 문서 수에 따라 min_cluster_size 동적 조정
  • 밀도가 낮은 키워드는 노이즈로 분류·제외
시각화 (UMAP)

고차원 벡터를 2D로 압축하여 클러스터 분포를 한눈에 파악

  • 카테고리별 문서 수에 따라 파라미터 (n_neighbors, min_dist, spread) 조정
  • 클러스터당 노출 키워드 수 제한 및 레이블 겹침 자동 조정
