프로젝트 설명

IFSCC 논문을 제출하는 연구 부서에서, 전체 논문 데이터를 기반으로 연구원들이 트렌드를 파악하고 다음 출원 주제를 발굴할 수 있도록 키워드 분석을 의뢰했습니다.

단순한 키워드 빈도 집계가 아닌, 카테고리별로 어떤 키워드들이 함께 등장하는지 군집화하여 연구 흐름의 맥락을 파악할 수 있도록 분석을 설계했습니다.

분석 결과는 사내 IFSCC 트렌드 발표, 사외 IFSCC 결과 발표에 활용되었으며, 직접 구축한 사내 IFSCC 논문 검색 사이트와 연결되어 클러스터 키워드를 검색어로 활용할 수 있도록 연동되었습니다.

수치 지표
  • 분석 대상 : 2025 IFSCC 전체 논문
  • 총 790편 / 15개 세션 카테고리
  • 카테고리별 클러스터링 결과 생성 (세션당 3~22개 클러스터)
배경 및 목표

IFSCC는 화장품 과학 분야 최대 국제 학술대회로, 매 회차 수백 편의 논문이 발표됩니다. 연구원이 전체 논문을 직접 읽고 트렌드를 파악하는 데는 물리적 한계가 있었고, 분석가에게 키워드 기반 트렌드 분석이 의뢰되었습니다.

15개 카테고리별 연구 트렌드를 키워드 군집으로 시각화하고, 그 결과를 발표 자료와 논문 검색 사이트에 실제로 연결하는 것

데이터 수집 및 전처리
데이터 수집
  • 2025 IFSCC 전체 논문 790편 PDF (연구원으로부터 직접 제공)
  • 논문 메타데이터 엑셀 (논문번호, 논문명, 세션 주제, Podium 여부)
전처리
  • PyMuPDF로 PDF 텍스트 추출
  • 메타데이터와 PDF 추출 데이터를 논문번호 기준으로 조인
  • 영문 텍스트 정규화 (유니코드 정규화, 소문자 변환, 특수문자 제거)
  • 불용어 제거 (일반 영문 불용어 + 논문 도메인 불용어 추가)
  • Bigram 포함 토큰화 (단일 키워드 + 2단어 연속 키워드 함께 추출)
  • min_df / max_df 기반 저빈도·고빈도 단어 필터링
  • TF-IDF 평균값 기준 상위 50% 키워드만 선별
분석 방법론
TF-IDF 벡터화
  • 카테고리별 전체 문서 대상 TF-IDF 계산 (sublinear_tf 적용)
  • min_df / max_df 기반 저빈도·고빈도 키워드 필터링
  • 키워드별 평균 TF-IDF 기준 상위 50% 키워드만 선별
  • 단일 키워드 + Bigram 함께 활용
클러스터링 (HDBSCAN)
  • 키워드 간 유사도를 코사인 거리로 계산
  • 군집 수를 사전에 지정하지 않는 밀도 기반 클러스터링 적용
  • 카테고리별 문서 수에 따라 min_cluster_size 동적 조정
  • 밀도가 낮은 키워드는 노이즈(-1)로 분류·제외
시각화 (UMAP)
  • 고차원 TF-IDF 벡터를 2D로 차원 축소
  • 카테고리별 문서 수에 따라 n_neighbors, min_dist, spread 파라미터 조정
  • 클러스터당 노출 키워드 수 제한 및 레이블 겹침 자동 조정 (adjustText)
  • 노이즈 클러스터 제외 후 저장
