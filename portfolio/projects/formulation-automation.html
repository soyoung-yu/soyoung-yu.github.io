프로젝트 설명

연구원이 "나이아신아마이드 넣은 미백 에센스 만들어줘" 라고 입력하면, AI가 자사 처방 DB를 참고해 실험 가능한 처방 3가지를 자동으로 설계해주는 시스템

배경 및 목표
배경

신규 처방 개발은 과거 유사 처방을 탐색하고 수정하는 방식으로 진행되는 경우가 많습니다. 이로 인해 연구의 출발점이 기존 처방에 제한되며, 고객 요구사항으로부터 다양한 설계 방향을 빠르게 탐색하는 데 한계가 있었습니다.

목적 및 목표

고객 요구사항을 실험 가능한 초기 배합안으로 전환하여, 연구원이 다양한 설계 방향을 보다 빠르게 탐색할 수 있도록 지원

  • 연구원이 자연어 형태의 요구사항을 입력하면, 내부 처방 데이터와 성분 지식을 활용하여 서로 다른 설계 전략을 가진 초기 배합안 3종을 자동 생성
  • 생성된 배합안은 연구원의 후속 실험과 최적화를 위한 출발점으로 활용
데이터 수집 및 전처리
활용 데이터

[자사 처방] 내부 실험 데이터

  • 주요 항목 : 벌크코드, 성분명, 함량, 성분 역할
  • 기간 : 2025-01-01 ~ 2026-05-31
  • 데이터 수 : 에센스 290건 (bulk_code 기준)

[자사 마케팅 키워드] 자사 처방과 연결된 외부 플랫폼 데이터

  • 주요 항목 : 벌크코드, 마케팅 키워드, 사용감 키워드
  • 기간 : 2023-04-01 ~ 2026-05-31
  • 데이터 수 : 에센스 166건 (bulk_code 기준)

[타사 전성분] 외부 플랫폼 데이터

  • 주요 항목 : 제품명, 전성분
  • 기간 : 2023-04-01 ~ 2026-05-31
  • 데이터 수 : 에센스 2,003건 (product_id 기준)
데이터 전처리
  • 자사 처방 데이터 : 제품을 구성하는 원료 정보(A) 테이블과 원료를 구성하는 성분 테이블(B)을 조인
  • 외부 플랫폼 데이터 : 제품의 전성분 포맷 정규화
프로세스

사용자 입력 → 질의 분석 → DB 조회 → 컨텍스트 구성 → AI 호출 → 검증 → 결과 저장

1단계 — 데이터 준비
  • 자사 처방 데이터 로드 및 성분별 통계치 계산 (사용 처방 수, 비율, 평균, 표준편차, 최솟값, 최댓값, 중앙값, p25, p75)
  • 자사 마케팅 키워드, 타사 전성분 데이터 로드
2단계 — 질의 분석
  • [Python 정확 매칭] 성분명 · 마케팅 키워드 · 함량(regex) 추출, ALIAS_HINTS 기반 관용명 매칭 (예: 시카 → 병풀추출물)
  • [LLM 1회 호출] 타겟 제품명 추출, Python이 놓친 성분·키워드 보완, 성분-함량 1:1 매핑
  • [Python 정확 매칭 2] 타겟 제품명으로 자사 처방 → 타사 제품 순서로 DB 탐색
3단계 — 컨텍스트 구성
  • 유사 처방 탐색 : 마케팅 키워드 매칭 처방 (그룹 A, 최대 3건) + 성분 매칭 처방 (그룹 B, 최대 3건)
  • 성분 통계 배정 : base 구조 성분 top 15 / 질의 성분 1순위 / 타겟·유사 처방 성분 2·3순위 / 범용 활성 성분 4순위
  • 허용 성분 목록 : 자사 처방 DB 내 미배정 성분 전체 제공
4단계 — LLM 호출
  • 타겟 처방 정보 · 성분 통계 · 유사 처방 · 허용 성분 목록 · 연구원 노하우 · 3안 설계 지침을 프롬프트로 조립
  • AWS Bedrock Claude에게 처방 3안을 JSON으로 생성 요청
  • Formula A: 심플·집중 효능 / Formula B: 올라운드 실용 처방 / Formula C: 프리미엄·차별화
5단계 — 검증 및 보정
  • LLM 생성 성분명의 자사 처방 등장 여부 확인 → 미등장 성분은 LLM에게 대체 성분 3개 제안 요청 후 교체 또는 제거
  • 전체 함량 합계 100% 여부 확인 → 정제수 함량 조절로 보정
6단계 — 결과 저장
  • CSV : 처방별 성분표
  • Excel : 처방 시트 + 통계 + 키워드 매핑 + 설계근거 + 비용내역 + 프롬프트
  • JSON : 성분 통계
비즈니스 제안 및 액션 아이템
연구원들의 암묵지 자산화 체계 구축
  • 연구원의 제형 설계 노하우, 원료 활용 경험, 문제 해결 사례 등을 문서화하여 조직 자산으로 축적
  • 향후 AI 기반 처방 생성 시스템의 지식 베이스로 활용 가능
AI 기반 Formulation Assistant 구축
  • 반복적인 벤치마킹 및 초안 설계 업무를 지원하여 연구 효율성 향상
  • 신규 연구원의 학습 지원 및 처방 설계 생산성 향상 도구로 활용 가능
Formulation SaaS 상품화 가능성 검토
  • 자체 연구 인력이 부족한 중소·중견 화장품 기업을 대상으로 AI 기반 처방 설계 서비스 모델 제안
  • 자연어 기반 처방 생성·타사 제품 벤치마킹·성분 추천 기능을 제공하는 구독형 서비스로 확장 가능성 확인
