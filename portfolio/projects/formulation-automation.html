프로젝트 설명

제형 연구원은 고객사의 개발 의뢰가 접수되면 요구사항과 유사한 기존 처방(백본 처방)을 찾은 후, 이를 기반으로 성분 및 함량을 조정하며 처방 개발을 진행합니다. 그러나 사내에는 수만 건의 처방 데이터가 축적되어 있음에도 불구하고, 원하는 조건에 부합하는 처방을 효율적으로 검색할 수 있는 체계가 부족하여 연구원 개인 또는 동료의 경험과 기억에 의존하는 경우가 많았습니다. 또한 신규 연구원의 경우 적절한 백본 처방을 찾고 고객 요구사항에 맞게 수정하는 과정에서 많은 시간이 소요되는 문제가 존재하였습니다.

이에 사내 처방 데이터와 성분 데이터, 외부 뷰티 플랫폼의 전성분 데이터를 활용하여 연구원의 자연어 요구사항을 기반으로 초기 처방을 자동 생성하는 LLM 기반 Formulation 자동화 로직을 설계하였습니다. LLM을 활용하여 사용자 질의에서 성분, 효능, 제형, 타겟 제품 정보를 추출하고, 내부 처방 통계 및 유사 처방 탐색 결과를 결합하여 처방을 생성하도록 구현하였습니다. 또한 도메인 제약조건을 프롬프트에 반영하여 생성 결과의 실무 활용성을 높였습니다.

이를 통해 연구원의 반복적인 백본 처방 탐색 업무를 지원하고, 신규 연구원의 처방 설계 진입 장벽을 낮출 수 있는 가능성을 확인하였습니다. 또한 내부 데이터를 활용한 LLM 기반 처방 설계 자동화의 실현 가능성을 검증하였습니다.

배경 및 목표

제형 연구원의 처방(Formulation) 연구 효율성을 높이기 위해 자연어 질의를 받아 초기 처방을 생성하는 LLM 기반 자동화 로직을 구현함

데이터 수집 및 전처리
데이터 수집

사내 DB

  • 처방 데이터
    • 약 25,000개 제품의 처방(Formulation) 데이터
    • 제품을 구성하는 원료, 성분, 함량
    • 시스템 DB의 2개의 테이블을 조인하여 활용
  • 성분 데이터
    • 성분에 대한 메타 데이터
    • 성분의 공식명칭, 역할 (용제, 유화제, 점증제 등)
    • 시스템 DB의 1개의 테이블을 활용

외부 구매 데이터 (뷰티 플랫폼)

  • 제품명, 제형 (카테고리)
  • 제품의 전성분 정보
데이터 전처리

사내 DB

  • 제품을 구성하는 원료 정보(A) 테이블과 원료를 구성하는 성분 테이블(B)을 조인

외부 구매 데이터

  • 제품의 전성분 포맷 정규화
분석 방법론
성분명 정규화 및 매핑
  • 외부 제품 전성분과 내부 성분 DB를 연결하기 위한 성분명 정규화 수행
  • Exact Match, Embedding Similarity, LLM 기반 보완을 활용하여 매핑 정확도 향상
LLM 기반 정보 추론 및 보완
  • 사용자 질의에서 성분, 효능, 제형, 타겟 제품 등의 핵심 정보를 추출하여 구조화
  • 자연어 형태의 요구사항을 처방 생성에 활용 가능한 구조화 데이터로 변환
통계 기반 컨텍스트 생성
  • 성분별 사용 빈도 및 함량 분포 산출
  • min, max, median, p25, p75 등의 통계 지표를 생성
  • 유사 처방, 성분 역할 등의 정보와 함께 컨텍스트로 구성되어 LLM 처방 생성 근거로 활용
LLM 프롬프트 엔지니어링 기반 처방 생성
  • 역할(Role), 지시사항(Instruction), 출력 포맷(Output Schema)을 정의한 프롬프트 설계
  • 사용자 요구사항, 성분 통계, 유사 처방 정보를 기반으로 초기 처방(Formulation) 자동 생성
  • 도메인 제약조건을 프롬프트에 반영하여 생성 결과의 실무 활용성 향상
  • 생성 결과에 대한 반복 테스트 및 프롬프트 개선을 통해 생성 품질 고도화
AI Agent 기반 개발 효율화
  • 처방 생성 로직을 단계별로 정의한 기획 문서 작성
  • Agent가 일관된 방식으로 개발할 수 있도록 개발 규칙 및 명세 문서화
  • Agent를 활용하여 코드 구현 및 반복 개선 수행
  • 연구원 피드백을 반영하여 처방 생성 로직 지속 고도화
분석 결과 및 인사이트
초기 처방 설계 자동화 가능성 확인
  • 연구원의 자연어 요구사항만으로 초기 처방 설계가 가능함을 확인
  • 내부 처방 데이터와 LLM을 결합하여 반복적인 벤치마킹 및 백본 처방 탐색 업무를 자동화할 수 있는 가능성 확인
데이터 기반 컨텍스트의 중요성 확인
  • 실제 처방 설계 프로세스를 반영하여 프롬프트를 설계할 경우 처방 생성 품질이 향상됨을 확인
  • 유사 처방, 성분 통계, 타겟 제품 정보 등을 함께 제공할 경우 생성 결과의 품질이 향상됨을 확인
  • LLM 단독 생성보다 내부 데이터를 활용한 컨텍스트 기반 생성 방식이 실무 활용성 측면에서 효과적임을 확인
비즈니스 제안 및 액션 아이템
연구원들의 암묵지 자산화 체계 구축 제안
  • 연구원의 제형 설계 노하우, 원료 활용 경험, 문제 해결 사례 등을 문서화하여 조직 자산으로 축적
  • 향후 AI 기반 처방 생성 시스템의 지식 베이스로 활용 가능
AI 기반 Formulation Assistant 구축
  • 반복적인 벤치마킹 및 초안 설계 업무를 지원하여 연구 효율성 향상 기대
  • 신규 연구원의 학습 지원 및 처방 설계 생산성 향상 도구로 활용 가능
Formulation SaaS 상품화 가능성 검토
  • 자체 연구 인력이 부족한 중소·중견 화장품 기업을 대상으로 활용 가능한 AI 기반 처방 설계 서비스 모델 제안
  • 자연어 기반 처방 생성, 타사 제품 벤치마킹, 성분 추천 기능 등을 제공하는 구독형 서비스로 확장 가능성 확인
