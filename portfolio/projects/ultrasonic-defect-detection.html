프로젝트 설명

고객사는 보일러 배관 용접부 결함을 비파괴 초음파 검사(PAUT)로 진행하고 있었고, 현업이 모든 검사 결과를 직접 확인하며 많은 시간을 소비하고 있었습니다.

전체 자동화가 목표가 아니었습니다. 제조 공정에서 결함 판정은 치명적인 단계이기 때문에, 현업의 검토 대상을 간추리는 부분 자동화를 목표로 설계했습니다.

수치 지표
  • Recall 0.98 달성 (미검출 최소화 목표 기준)
배경 및 목표

중공업 제조 공정에서 결함 미검출은 치명적 리스크입니다. 전수 검토에 소요되는 시간을 줄이되, 안전성을 유지하기 위해 Recall을 최우선 지표로 설정했습니다. 전체 자동화보다는 현업의 검토 범위를 줄이는 부분 자동화를 목표로 했습니다.

데이터 수집 및 전처리
데이터
  • 보일러 배관 용접부 비파괴 초음파 검사(PAUT) 이미지
객체 경계 박스 재생성
  • 라벨링 시스템 한계로 기존 경계 박스가 객체를 정확히 표현하지 못하는 문제 발생
  • 이미지에서 경계 박스 영역 크롭 → RGB → HSV 색공간 변환 → 결함 부위 색상 마스크 추출 → 모폴로지 연산으로 마스크 정제 → 새로운 경계 박스 생성
런타임 개선
  • 2 stage detector 사용으로 속도 이슈 존재
  • 데이터 stack 로직을 numpy 중심으로 변경
  • 추론 코드 하드코딩 처리로 불필요한 연산 제거
  • 데이터 로더 내부/외부 연산 속도 비교 후 최적화
모델 설계 및 핵심 의사결정
  • 성능 우선 목표 → 2 stage detector (Faster RCNN) 선택
  • 미검출 최소화 목적에 따라 Recall을 주요 평가 지표로 설정
결과 및 성과
  • Recall 0.98 달성
  • 런타임 개선으로 실운영 환경 적용 가능성 확보
