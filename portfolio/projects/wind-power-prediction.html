프로젝트 설명

재생에너지 입찰 제도 개선으로 더 정밀한 발전량 예측이 요구되었습니다. 기존 모델은 풍속 기반으로 설계되어 있었는데, 개선된 입찰 제도에서 풍속의 큰 변동성은 비용에 직접 영향을 주는 리스크였습니다.

이 프로젝트는 한 가지 질문에서 출발했습니다. "풍속 없이 발전량만으로 더 안정적인 예측이 가능한가?"

풍속 의존도를 제거하고 과거 발전량 기반 시계열 예측으로 접근 방식을 전환했습니다. 메인 모델에는 VMD 신호 분해 기법을 적용해 발전량 자체에서 특성을 학습하도록 했고, 발전기 내부 센서 데이터(온도, 방향, 각도)를 활용한 서브 모델로 메인 모델의 에러를 보정하는 2단 구조를 설계했습니다.

수치 지표
  • 기존 모델 NMAE 약 12% → 새 모델 NMAE 약 4% (약 8% 향상)
  • 풍속 예측 단계 제거로 추론 런타임 단축
배경 및 목표

재생에너지 입찰 제도 개선으로 발전량 예측 정확도가 직접적인 비용 리스크와 연결되었습니다. 풍속 변동성에 취약한 기존 모델을 대체하기 위해, 풍속에 의존하지 않는 새로운 예측 구조를 설계하는 것이 목표였습니다.

데이터 수집 및 전처리
데이터
  • 과거 발전량 시계열 데이터
  • 발전기 내부 센서 데이터 약 65개 (온도, 각도, 방향 등 발전기 상태 관련)
전처리 및 변수 선정
  • 센서 데이터 추이 및 분포 확인
  • 센서 간 상관관계 분석
  • 선형 회귀 f(x, 풍속)로 각 센서의 발전량 영향력 확인
  • SHAP Value로 변수 중요도 및 방향 확인 후 최종 변수 선정
모델 설계 및 핵심 의사결정
메인 모델 (발전량 예측)
  • 풍속 제거 → 과거 발전량 단일 변수 기반 시계열 예측으로 전환
  • VMD(변동모드분해) 적용으로 발전량 신호에서 특성 학습
서브 모델 (에러 보정)
  • 메인 모델 잔차에 센서 데이터를 변수로 추가한 보정 모델 구축
  • SHAP 기반 변수 선정으로 센서 의존도 최소화
모듈화
  • 추론 / 학습 및 평가 / 시각화 모듈 분리
  • config 파일 기반 통합 관리 구조 구축
결과 및 성과
  • 기존 모델 대비 NMAE 약 8% 향상 (12% → 4%)
  • 풍속 예측 → 발전량 예측의 2단계 추론 구조를 발전량 직접 예측 1단계로 축소, 런타임 개선
