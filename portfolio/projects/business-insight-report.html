프로젝트 설명

사내 데이터 서비스 이용률이 저조한 문제를 분석한 결과, 서비스 자체의 문제가 아니라 직원들이 데이터로 무엇을 할 수 있는지 경험해본 적이 없다는 것이 근본 원인이었습니다. 데이터를 제공하는 것만으로는 활용으로 이어지지 않는다고 판단하여, 직원들이 데이터의 쓸모를 직접 체감할 수 있도록 정기 인사이트 리포트를 기획했습니다.

리포트는 매 회차 다른 비즈니스 주제를 선정해, 외부 시장 데이터와 사내 연구·생산 데이터를 결합하여 분석했습니다. 단순한 수치 나열이 아닌 하나의 스토리라인으로 구성하여, 비전문가도 읽으면 바로 업무에 적용할 수 있는 형태로 제작했습니다.

12회 정기 리포트 발행
540명 대상 직원 배포
100회+ 배포 후 3일 평균 조회
1건 → 4건 월 데이터 분석 요청 증가

가장 유의미한 변화는 현업 부서가 먼저 데이터와 대시보드를 요청하기 시작했다는 점입니다. 기존에는 데이터 요청이 거의 없거나 단순 목록 조회 수준이었다면, 리포트 배포 이후에는 "선크림 중 톤업 선크림의 비율을 볼 수 있냐"처럼 스스로 질문을 설계하는 방식으로 변화했습니다. 대시보드 요청도 팀이 먼저 제안하던 방식에서 현업이 직접 요청하는 방식으로 전환되었습니다.

배경 및 목표

데이터 서비스를 만들어 제공해도 활용이 일어나지 않는 상황에서, 문제의 원인을 서비스 품질이 아닌 직원들의 데이터 활용 경험 부재로 진단했습니다. 현업에 바로 적용할 수 있는 인사이트를 전달함으로써 데이터의 쓸모를 체감하게 하고, 이를 통해 자발적인 데이터 활용 수요를 만드는 것을 목표로 했습니다.

데이터 수집 및 전처리
데이터 수집
  • 외부 구매 데이터: 제품 메타데이터, 판매·인기 랭킹, 소비자 리뷰
  • 사내 DB: 화장품 연구 개발 데이터, 의뢰 및 생산 데이터
전처리
  • 수집 시점별 제품 데이터 중 최신 기준으로 메타데이터 구성
  • 중복 리뷰 제거로 키워드 빈도 왜곡 방지
  • 리뷰 수, 평균 평점, 평균 랭킹 등 제품 단위 분석 지표 생성
  • 옵션·용량 차이로 분리된 동일 제품 통합
  • 의뢰 정보와 생산 실적 데이터를 조인하여 제품 흐름 추적
분석 방법론
탐색적 데이터 분석
  • Python, SQL로 분석 목적에 맞는 데이터 마트 설계
  • 제형·브랜드·제조사 관점의 데이터 분포 및 특성 파악
  • 랭킹, 점유율, 성장률, 시계열 추세 등 주요 지표 분석
LLM 기반 텍스트 분류
  • 비정형 리뷰 데이터에서 분석 대상을 자동으로 분류하기 위한 프롬프트 설계
  • 립앤치크 리뷰에서 '립 사용 경험'과 '치크 사용 경험'을 자동 분리하여 각각 분석
AI Agent 활용
  • 대용량 데이터 전처리 코드 초안 생성에 AI Agent 활용
  • 생성된 코드를 검증·수정하여 분석 파이프라인에 적용
분석 결과 및 인사이트
선케어 세부 제형 트렌드 분석
  • 선케어 시장이 선크림·선스틱 중심에서 선세럼·선젤·선파우더 등 세분화된 제형으로 확대되는 추세 확인
  • 자사의 선세럼은 경쟁사 대비 랭킹·리뷰 기준으로 상위권에 위치

시장을 주도하고 있는 전략 제형으로 판단했습니다.

립앤치크 리뷰 분석
  • 립 관련 부정 리뷰 비율은 약 30%로, 치크 약 17% 대비 높게 나타남
  • 부정 리뷰는 주로 발림성과 지속력 항목에서 발생

현재 립앤치크 시장은 치크 사용 경험에 최적화된 반면, 립 경험 개선 여지가 있음을 확인했습니다.

제형별 라이프사이클 분석
  • 쿠션·립틴트·에센스·크림 4개 제형의 출시~단종 데이터를 분석한 결과, 제형마다 성장과 하락의 구조가 뚜렷하게 다름을 확인
  • 쿠션은 인기 제품일수록 느리게 성장하고 오래 유지되는 스테디셀러 구조
  • 립틴트는 초반 빠른 성장이 장기 생존의 전제 조건
  • 에센스는 인기 제품일수록 빠른 히트 후 빠르게 교체되는 트렌드 소모 구조
  • 크림은 트렌디셀러와 스테디셀러의 성격이 혼재
비즈니스 제안 및 액션 아이템
  • 선세럼은 선케어 시장에서 자사의 강점 제형으로, 시장 공략 시 핵심 카테고리로 우선 활용할 것을 제안했습니다.
  • 립앤치크 제품 개발 시 립의 발림성·지속력 개선이 주요 차별화 포인트가 될 수 있습니다.
  • 제형별 라이프사이클 구조를 사전에 파악하고 제품 포지션을 설계 및 영업할 것을 제안했습니다.
