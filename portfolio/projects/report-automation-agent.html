프로젝트 설명

사내 직원들에게 제공되던 비즈니스 인사이트 리포트는 매 회차 분석가가 직접 데이터를 분석하고, 시각화를 그리고, 인사이트 문장을 작성하는 과정을 반복해야 했습니다.

자원 효율화를 위해, 리포트 제작의 일부 과정을 AI 코딩 에이전트에게 위임하는 자동화 파이프라인을 설계했습니다. 핵심은 에이전트에게 "무엇을 만들라"고 지시하는 데 그치지 않고, 리포트의 목적·분석 및 시각화 규칙·인사이트 작성 규칙을 문서화하여 에이전트가 따라야 할 표준 매뉴얼로 제공한 것입니다. 이를 통해 매 회차 다른 주제를 다루면서도 일관된 품질과 톤을 유지하는 반자동 리포트 생산 체계를 구축했습니다.

최종 산출물

사전에 집계된 분석용 데이터(csv)와 리포트 제작 규칙 문서를 참고하여, AI 에이전트가 분석·시각화·인사이트 문장·결론까지 규칙에 맞춰 자동 생성하여 배포 가능한 형태(ipynb/html)의 리포트 초안을 산출하는 시스템

배경 및 목표
배경

리포트 제작이 전적으로 수작업에 의존하고 있어, 발행 주기 단축과 품질 표준화, 자원 효율화에 한계가 있었습니다.

목적 및 목표

AI 에이전트가 조직의 리포트 표준을 그대로 따르도록 설계하여, 제작자와 무관하게 일관된 품질의 리포트를 반복 생산할 수 있는 체계 구축

시스템 설계 (에이전트 지시 문서 구조화)

project.md

리포트의 목적, 독자(연구원/마케팅 조직), 활용 데이터 정의 → 에이전트에게 "왜 이 리포트가 필요한지" 비즈니스 맥락 제공

rules.md

시각화 규격(색상·폰트·범례 통일), 인사이트 문장 규칙(수치 포함 필수, 문장 수·종결어미 통일), 결론 구조(요약/마케팅 시사점/연구원 시사점 3단 구성)까지 명문화한 작성 규칙집

report.md

과거 발행 리포트 히스토리 → 리포트의 구성 및 전개 방식을 참고할 수 있는 기존 리포트 내용

csv/*.csv

분석 목적에 맞게 사전 집계된 데이터셋

프로세스

AI Agent에게 아래의 프로세스를 단계별로 지시

  1. 데이터 준비 — 리포트 주제에 맞는 데이터를 사전 집계하여 csv로 정리
  2. 에이전트 컨텍스트 구성 — project.md·rules.md·report.md를 에이전트에게 제공
  3. 분석 및 시각화 — 에이전트가 규칙에 따라 Plotly 기반 시각화 생성
  4. 인사이트 문장 생성 — 그래프 해석과 핵심 인사이트를 규칙에 맞춰 자동 작성 (수치·순위 필수 포함, 추측성 문장 배제)
  5. 결론 도출 — 전체 요약 → 마케팅 조직 시사점 → 연구원 시사점 순으로 3단 결론 자동 구성
  6. 산출물 저장 — ipynb(재현 가능한 분석 노트북), html(배포용) 형태로 저장
결과 및 성과
  • 5회차 리포트를 본 파이프라인으로 제작 (ex. 얇아지는 베이스 메이크업 시장 분석, 더마 코스메틱 시장 종합 분석 등)
  • 여러 단계의 가설과 검증을 거치며 하나의 핵심 인사이트로 연결되는 스토리라인 구조를 규칙 기반으로 자동 구현
  • 사람이 매 회차 직접 설계 및 분석하던 과정을, 재사용 가능한 규칙 문서 기반 워크플로우로 전환
  • 리포트 1건당 분석 시간 감소 (6일 → 1시간)
