비즈니스 인사이트 리포트

기술 스택
Python SQL AWS Bedrock LLM Codex Claude Code Figma
프로젝트 설명

사내 데이터 서비스 이용률이 저조한 문제를 분석하는 과정에서, 서비스 자체의 기능이나 품질보다 직원들의 데이터 활용 경험 부족이 근본 원인이라고 판단했습니다. 이에 데이터를 단순히 제공하는 방식에서 벗어나, 실제 업무에 적용 가능한 인사이트를 전달함으로써 직원들의 데이터 활용 경험을 확대하고자 정기 인사이트 리포트 발행 프로젝트를 기획했습니다.

리포트는 매 회차 서로 다른 비즈니스 주제를 선정하여 외부 시장 데이터와 사내 연구·생산 데이터를 분석하는 방식으로 제작했으며, 비전문가도 쉽게 이해할 수 있도록 차트 설계와 인사이트 해석에 집중했습니다. 또한 단순 분석 결과 나열이 아닌 하나의 스토리라인을 기반으로 구성하여 데이터가 자연스럽게 의사결정으로 연결될 수 있도록 설계했습니다.

총 12회의 리포트를 제작·배포했으며, 배포 후 3일 평균 조회수 100회 이상을 기록했습니다. 추가 데이터 분석 요청은 기존 대비 약 4배, 신규 대시보드 구축 요청은 약 2배 증가하는 성과를 달성했고, 직원들의 데이터 활용 경험 확대와 데이터 기반 의사결정 문화 형성에 기여했습니다.

배경 및 목표

사내 직원들의 데이터 활용 경험을 유도하기 위해 현업에 바로 적용할 수 있는 인사이트를 포함한 분석 리포트를 정기적으로 배포했습니다.

데이터 수집 및 전처리
데이터 수집
  • 외부 구매 데이터: 제품 메타데이터, 제품 판매·인기 랭킹 데이터, 소비자 리뷰 데이터
  • 사내 DB: 화장품 연구 개발 데이터, 의뢰 및 생산 데이터
전처리
  • 동일 제품의 수집 시점별 정보 중 최신 데이터를 기준으로 제품 메타데이터 구성
  • 중복 리뷰 데이터를 제거하여 리뷰 수와 키워드 빈도 왜곡 방지
  • 리뷰 수, 평균 평점, 평균 랭킹 등 제품 단위 분석 지표 생성
  • 옵션, 용량 차이로 분리된 동일 제품 통합
  • 담당 연구팀 정보 매핑 및 내부 제형 카테고리와 외부 뷰티 플랫폼 카테고리 매칭
  • 의뢰 정보와 생산 실적 데이터를 조인하여 제품 흐름 추적
분석 방법론
탐색적 데이터 분석
  • Python, SQL을 활용해 분석 목적에 맞는 데이터 마트 설계
  • 제형, 브랜드, 제조사 등의 관점에서 데이터 분포 및 특성 파악
  • 리뷰 수, 랭킹, 점유율, 성장률, 시계열 추세 등 주요 지표 분석
LLM 프롬프트 기반 텍스트 분류
  • 비정형 리뷰 데이터 분석을 위해 입출력 포맷과 분석 기준을 정의한 프롬프트 설계
  • 리뷰 내 분석 대상 자동 분류: 예를 들어 립앤치크 리뷰에서 립 사용 경험과 치크 사용 경험 리뷰를 분리
AI Agent 활용
  • 대용량 데이터 전처리 및 가공을 위한 코드 초안 생성에 AI Agent 활용
  • 생성된 코드를 검증 및 수정하여 분석 파이프라인에 적용
분석 결과 및 인사이트
선케어 세부 제형 트렌드 분석
  • 선케어 시장이 선크림·선스틱 중심에서 선세럼, 선젤, 선파우더 등 세분화된 제형으로 확대되고 있음을 확인
  • 선세럼이 선쿠션을 제치며 선크림, 선스틱 다음으로 제품 수 기준 3위를 차지
  • 다른 제조사에 비해 자사의 선세럼이 랭킹, 리뷰 기준으로 상위권에 위치

선케어 약세 속에서도 선세럼은 자사가 시장을 주도하고 있는 전략 제형으로 판단했습니다.

립앤치크 리뷰 분석
  • "립앤치크는 립과 치크 모두를 만족시키는 멀티 제형으로 기능하고 있는가?"라는 가설에서 출발
  • 립 관련 리뷰의 부정 비율은 약 30%로, 치크 관련 리뷰의 부정 비율 17% 대비 높게 나타남
  • 립에 대한 부정 리뷰는 발림성과 지속력 항목에서 주로 발생

현재 립앤치크 시장은 립보다 치크 사용 경험 최적화에 상대적으로 집중되어 있는 것으로 판단했습니다.

비즈니스 제안 및 액션 아이템
  • 선세럼은 선케어 시장에서 자사가 강점을 보유한 전략 제형으로 판단되며, 선케어 시장 공략 시 핵심 카테고리로 활용이 필요합니다.
  • 립앤치크 제품 개발 시 립 사용 시의 발림성 및 지속력 개선이 주요 차별화 포인트가 될 수 있습니다.
