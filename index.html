기술 스택

프로젝트 설명

사내 데이터 서비스 이용률이 저조한 문제를 분석하는 과정에서, 서비스 자체의 기능이나 품질보다 직원들의 데이터 활용 경험 부족이 근본 원인이라고 판단했습니다. 이에 데이터를 단순히 제공하는 방식에서 벗어나, 실제 업무에 적용 가능한 인사이트를 전달함으로써 직원들의 데이터 활용 경험을 확대하고자 정기 인사이트 리포트 발행 프로젝트를 기획했습니다.

리포트는 매 회차 서로 다른 비즈니스 주제를 선정하여 외부 시장 데이터와 사내 연구·생산 데이터를 분석하는 방식으로 제작했으며, 비전문가도 쉽게 이해할 수 있도록 차트 설계와 인사이트 해석에 집중했습니다. 또한 단순 분석 결과 나열이 아닌 하나의 스토리라인을 기반으로 구성하여 데이터가 자연스럽게 의사결정으로 연결될 수 있도록 설계했습니다.

총 12회의 리포트를 제작·배포했으며, 배포 후 3일 평균 조회수 100회 이상을 기록했습니다. 추가 데이터 분석 요청은 기존 대비 약 4배, 신규 대시보드 구축 요청은 약 2배 증가하는 성과를 달성했고, 직원들의 데이터 활용 경험 확대와 데이터 기반 의사결정 문화 형성에 기여했습니다.

글로벌 연구소 법인 KPI 측정을 위한 SSOT 설계

기술 스택
Python SQL LLM (Claude) Codex
프로젝트 설명

연구소 각 법인은 매월 의뢰, 확정, 초도, 매출 KPI를 수작업으로 집계하여 중앙 부서(GCC)에 제출하고 있었습니다. GCC에서 KPI 정의 및 산출 기준을 제시하고 있었으나, 실제 집계 과정은 각 법인의 엑셀 기반 수작업에 의존하고 있어 휴먼 에러 발생 가능성이 높았으며, KPI 기준 해석의 차이로 인해 법인 간 성과 비교의 신뢰성이 낮은 상태였습니다.

이에 시스템 DB를 기반으로 KPI 집계 과정을 원천부터 검증하고, 법인별 KPI 산출 로직과 예외 처리 기준을 분석하였습니다. 그 결과 동일 KPI에 대해서도 법인마다 서로 다른 집계 기준과 예외 규칙이 적용되고 있음을 확인하였으며, 관계 부서 및 현업 연구소와 협의를 통해 KPI 정의를 재정립하고 글로벌 공통 KPI 체계를 수립하였습니다. 최종적으로 표준화된 KPI 로직을 기반으로 SSOT(Single Source of Truth)를 구축하고 KPI 집계 자동화 체계를 구현하였습니다.

배경 및 목표

기존 각 법인이 수작업으로 관리하던 KPI 집계 체계를 시스템 DB 기반의 자동화 방식으로 전환하고, 법인별로 상이했던 KPI 산정 기준을 표준화하여 글로벌 연구소의 성과를 동일 기준으로 측정할 수 있는 SSOT(Single Source of Truth)를 구축하고자 함.

  • 엑셀 형태의 수작업 보고 자료 확보

  • 확정/초도 : 자재 마스터 테이블을 기반으로 KPI 집계용 데이터 마트 구축
  • 매출 : 관계 부서와 협업하여 법인별 자재 매출 데이터 마트 확보

  • KPI 정의, 집계 기준, 제외 조건 등의 차이를 분석하여 표준 KPI 산출 기준 수립

  • LLM을 활용해 데이터 간 차이점 및 원인 후보를 탐색하고 검증 과정 지원

법인별 KPI 정의 및 집계 기준 차이 발견

동일한 KPI 명칭을 사용하고 있었으나, 실제 집계 기준은 법인별로 상이하게 운영되고 있음을 확인

  • 확정일 기준 차이

  • 의뢰/개발 법인 활용 기준 차이
    • 일부 법인 : 의뢰법인 기준으로 의뢰 수 집계
    • 그외 법인 : 개발법인 기준으로 의뢰 수 집계
법인별 예외 처리 로직 존재 확인
  • 일부 법인은 현지 운영 환경을 반영하여 별도의 제외 조건을 적용하고 있음을 발견
  • 예) 특정 고객사의 과도한 의뢰 건을 집계 대상에서 제외
  • 법인의 주관적 판단에 따라 KPI 수치가 달라질 수 있음을 확인

글로벌 연구소의 KPI는 법인별로 상이하게 운영되고 있어, 성과를 동일 기준에서 비교하기 어려움

비즈니스 제안 및 액션 아이템
KPI 정의 재정립 및 표준화

관계 부서와 논의하여 KPI가 측정하고자 하는 성과의 정의를 기준으로 글로벌 공통 KPI 체계를 재검토

KPI 기준 재검토 결과

  • 확정 KPI 기준 표준화
    • 기존 확정 KPI는 BOM 상태값 1111 시점을 기준으로 운영되고 있었음
    • 그러나 KPI의 목적을 고려할 때, 실제 처방 확정 시점인 BOM 상태값 1110이 더 적합하다고 판단
    • 이에 확정 KPI 기준을 BOM 상태값 1110 기준으로 통일함
  • 의뢰 KPI 기준 표준화
    • 기존 의뢰 KPI는 의뢰 법인을 기준으로 운영되고 있었음
    • 그러나 KPI의 목적이 연구소의 성과 측정에 있는 만큼, 실제 개발을 수행한 연구소를 기준으로 평가하는 것이 적절하다고 판단
    • 이에 의뢰 KPI 집계 기준을 개발 법인 기준으로 통일함
예외 처리 기준 정비
  • KPI 목적에 부합하는 예외 조건은 유지하고, 공정성을 저해하는 예외 조건은 제거
글로벌 연구소 KPI SSOT 구축
  • KPI 정의, 집계 기준, 예외 처리 조건을 표준화하여 글로벌 연구소 공통 KPI 체계 구축
  • 법인 간 성과 비교의 신뢰성을 확보하고 KPI 자동 집계 기반 마련
